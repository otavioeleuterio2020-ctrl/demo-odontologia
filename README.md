# Demo Odontologia
Site estático (HTML/CSS/JS). Edite o objeto `CFG` no fim de `index.html` (WhatsApp, endereço, horários, Instagram, mapa).
Vídeo do hero (fundo escuro cinematográfico com camadas azul-marinho/preto; sem vídeo, roda um carrossel de imagens com movimento suave): adicione `video/hero.mp4` (1080p) e `video/hero-4k.mp4`; o site os detecta automaticamente.
